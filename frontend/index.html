Connecting…

Click or tap to select a pixel. Drag to pan and pinch or scroll to zoom. With the canvas focused, use arrow keys to select, Shift and arrow keys to move ten cells, and Enter or Space to place. You can also use the coordinate fields. Open the top-right coordinate readout or press ? for controls and help.

Canvas controls

Choose a cell from 0 to 511. The corner readout measures from the center.

Choose a color, select a pixel, then confirm with the button at the bottom. A saved pixel is shared with everyone. Each browser waits five seconds between pixels; shared networks also have a small drawing budget.

Drag to move around. Scroll or pinch with two fingers to zoom. You can select exact coordinates with X and Y. On the canvas, arrow keys move the selection; Enter or Space places it.

Your selection stays until the server confirms it. If the connection fails, check the canvas before trying again.

Privacy and local data

This canvas is public. Pixels are visible to everyone and kept in the drawing and its backups. Do not put personal or sensitive information in the drawing.

Your browser stores a random ID in local storage to enforce the five-second drawing wait. There are no analytics or advertising cookies. If storage is blocked, an ID lasts for the current page.

The server temporarily keeps that ID and a hash of your network address for drawing and connection limits. Hashes are pseudonymous, not anonymous. Expired drawing limits are removed at the next checkpoint, normally within 30 seconds. Connection limits expire after a minute without activity. They are not included in the independent hourly backups; those contain only pixels and the drawing version. Uploads stay in the active backup folder for approximately 30 days. Archived and offline backups can retain the public drawing longer, including indefinitely.

Access logs contain request counts, status, size and duration, without your address, browser details or URL. Technical error logs can contain network addresses. Logs rotate daily with fourteen archives; journal entries expire after fourteen days.

Resetting the browser ID clears this site's local identity and reloads the page. Your public pixels remain. Shared-network drawing limits still apply.
